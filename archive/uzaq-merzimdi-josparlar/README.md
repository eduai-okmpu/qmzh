# Ұзақ мерзімді жоспарлар каталогы

Дереккөз: ҚР Оқу-ағарту министрінің 2022 жылғы 16 қыркүйектегі № 399 бұйрығы (НҚА тізілімі № 29767) — «Бастауыш, негізгі орта және жалпы орта білім деңгейлерінің жалпы білім беретін пәндері мен таңдау курстары бойынша үлгілік оқу бағдарламаларын бекіту туралы». Әр файл — бұйрықтың бір қосымшасы (үлгілік оқу бағдарламасы + оның ішіндегі «…іске асыру жөніндегі ұзақ мерзімді жоспар» параграфы).

Барлығы: 132 қосымша, оның 119-інде ұзақ мерзімді жоспар бар.

Белгілер: ✅ — ұзақ мерзімді жоспар бар; ➖ — жоқ (мыс. «Әліппе», таңдау курстары); ❌ — қосымша алып тасталған.
