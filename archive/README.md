# Архив: ҚМЖ жасауға арналған нормативтік база және ұзақ мерзімді жоспарлар

Бұл папкада ҚМЖ (қысқа мерзімді жоспар) генераторына қажетті **ресми** дереккөздер сақталған.
Ешқандай мәтін ойдан құрастырылмаған: барлық файлдар — Қазақстан Республикасының нормативтік
құқықтық актілерінің (НҚА) мәтіндері немесе ресми ұйымның әдістемелік басылымы.

Жиналған күні: **2026-11-07**.

### 2. Мұғалім қандай жоспарларды жазуға міндетті

№ 130 бұйрықтың 3-қосымшасы бойынша (орта білім беру ұйымдары), барлық пән педагогтері:

* **күн сайын**, сабақ кестесіне сәйкес — **қысқа мерзімді (сабақ) жоспарды** (қағаз немесе электрондық word/pdf) жүргізеді;
* **оқу жылы басталғанға дейін бір рет** — пәндер бойынша **орта мерзімді (күнтізбелік-тақырыптық) жоспарды** әзірлейді.

**Ұзақ мерзімді жоспар** мұғалім жазатын құжат емес: ол **№ 399 бұйрықпен бекітілген үлгілік оқу
бағдарламасының құрамында** («…үлгілік оқу бағдарламасын іске асыру жөніндегі ұзақ мерзімді жоспар»
параграфы) беріледі. Бағдарлама мәтінінде былай жазылған: «Осы оқу бағдарламасы … ұзақ мерзімді жоспарға
сәйкес іске асырылады». Сондықтан ҚМЖ-дағы «Оқу бағдарламасына сәйкес оқыту мақсаттары» осы ұзақ
мерзімді жоспардан (бөлім → бөлім мазмұны → оқыту мақсаттарының кодтары, мыс. `7.1.2.1`) алынады.

### 3. ҚМЖ-ның міндетті нысаны (№ 130 бұйрық, 4-қосымша, 17.03.2023 № 68 редакциясы)

Нысанның тақырыбы: білім беру ұйымының атауы, «Қысқа мерзімді (сабақ) жоспары», сабақтың тақырыбы.
Міндетті тармақтар:

* Бөлім
* Педагогтің тегі, аты, әкесінің аты (болған жағдайда)
* Күні
* Сынып
* Қатысушылар саны
* Қатыспағандар саны
* Сабақтың тақырыбы
* Оқу бағдарламасына сәйкес оқыту мақсаттары
* Сабақтың мақсаты
* **Сабақтың барысы** кестесі: Сабақтың кезеңі/уақыт · Педагогтің әрекеті · Оқушының әрекеті · Бағалау · Ресурстар

Бұйрықта: «Сабақ жоспарының аталған тармақтары міндетті болып табылады». Сыныпта мүмкіндігі шектеулі
оқушылар болса, әдістемелік бірлестік мақұлдаған жеке бағдарламаларды бейімдеу әрекеттері де қарастырылады.

Орта мерзімді (КТЖ) нысаны: «___ пәні ___ сыныбы, Барлығы: ___ сағат, аптасына: ___ сағат»;
бағандары: № р/с · Бөлім/Ауыспалы тақырыптар · Сабақтың тақырыбы · Оқу мақсаттары · Сағат саны · Мерзімі · Ескерту;
І–IV тоқсандар бойынша.

## Дереккөздер және сенімділік

* Заңды күші бар ресми мәтіндер — [adilet.zan.kz](https://adilet.zan.kz) (Әділет министрлігінің «Әділет» АҚЖ).
  Бұл портал JavaScript қолданбасы, ал оның API-і авторизация талап етеді, сондықтан мәтіндер оның
  айнасы — [zakon.uchet.kz](https://zakon.uchet.kz) сайтынан алынды. Әр файлдың басында екі сілтеме де бар.
* Мәтіндер HTML → Markdown форматына `pandoc` арқылы **автоматты түрде** түрлендірілді, мазмұны өзгертілмеген.
  Күрделі кестелер (біріктірілген ұяшықтар) HTML `<table>` күйінде қалдырылды.
* Түпнұсқа HTML беттері `_derekkozder/` ішінде, `SHA256SUMS` бойынша тексеруге болады.
