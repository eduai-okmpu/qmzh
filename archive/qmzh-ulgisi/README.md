# ҚМЖ құрылымы: ресми нысан және іс жүзіндегі үлгі

Бұл құжат ҚМЖ генераторы үшін ҚМЖ-ның қандай бөлімдерден тұратынын сипаттайды.
Онда тек құрылымы бар, ешбір ҚМЖ-ның мазмұны көшірілмеген.

## 1. Ресми нысан (міндетті)

Дереккөз: ҚР БҒМ 2020 ж. 6 сәуірдегі № 130 бұйрығы, 4-қосымша (17.03.2023 № 68 редакциясы).
Толық мәтіні: [`../zannama/04-pedagog-qujattary-buiryq-130-V2000020317.md`](../zannama/04-pedagog-qujattary-buiryq-130-V2000020317.md).

**Тақырып бөлігі:**

* білім беру ұйымының атауы;
* «Қысқа мерзімді (сабақ) жоспары»;
* сабақтың тақырыбы.

**Міндетті тармақтар:**

| Тармақ |
|---|
| Бөлім |
| Педагогтің тегі, аты, әкесінің аты (болған жағдайда) |
| Күні |
| Сынып |
| Қатысушылар саны |
| Қатыспағандар саны |
| Сабақтың тақырыбы |
| Оқу бағдарламасына сәйкес оқыту мақсаттары |
| Сабақтың мақсаты |

**Сабақтың барысы** кестесінің бағандары:

| Сабақтың кезеңі/уақыт | Педагогтің әрекеті | Оқушының әрекеті | Бағалау | Ресурстар |
|---|---|---|---|---|

## 2. Іс жүзінде қолданылатын үлгі

Бұл бөлімнің дереккөзі — пайдаланушы 2026-11-10 жүктеген физика ҚМЖ-лары:
* 7, 9, 10, 11-сыныптар, 2-тоқсан және 3-тоқсан;
* барлығы 6 тоқсандық жинақ, әрқайсысында 12–23 сабақ;
* «USTAZ tilegi» (ust.kz) жасаған, тақырыптық бетінде «№472 бұйрығы бойынша жасалған ҚМЖ» деп жазылған.

Файлдардың өзі репозиторийге **салынбады**. Олардың бірінші бетінде авторлық құқық туралы ескерту бар:
«сатып алған ҚМЖ-ны тарату туралы факт анықталған жағдайда әкімшілік айыппұл салынады».

Әр сабақ **екі кестеден** тұрады.

### 2.1. Тақырып кестесі (2 баған)

| Жол | Ескерту |
|---|---|
| Бөлімі: | ресми нысанда бар |
| Педагогтің аты-жөні: | ресми нысанда бар |
| Күні: | ресми нысанда бар |
| Сыныбы: · Қатысушылар саны: · Қатыспағандар саны: | үшеуі бір жолда |
| Сабақтың тақырыбы: | ресми нысанда бар |
| Оқу бағдарламасына сәйкес оқу мақсаты | оқу мақсатының коды және мәтіні, мыс. `9.2.2.1 …` |
| Сабақтың мақсаты: | көбіне «Барлық оқушылар… / Көпшілігі… / Кейбіреуі…» түрінде |
| **Бағалау критерийлері** | ресми нысаннан тыс, қосымша |
| **Құндылықтарға баулу** | ресми нысаннан тыс, қосымша |

### 2.2. Сабақтың барысы кестесі (5 баған)

| Сабақ кезеңі/Уақыты | Педагогтің іс-әрекеті | Оқушының іс-әрекеті | Бағалау | Ресурстар |
|---|---|---|---|---|
| Сабақтың басы (≈5 мин) | ұйымдастыру, өткенді еске түсіру, әдіс атауы | … | Дескриптор | оқулық, ДК экраны, т.б. |
| Сабақтың ортасы | тапсырмалар (1-, 2-тапсырма…), әдіс атауы | … | Дескриптор, балл | … |
| Сабақтың соңы | жинақтау, рефлексия | … | Дескриптор / жалпы балл | … |

Баған атауларында «әрекеті» емес, **«іс-әрекеті»** деп жазылған. Мағынасы бірдей, сондықтан бұл ресми нысанға сай.

Кейбір жинақтарда кестенің соңында тағы мына бөлімдер бар:

* **Саралау**: «Сіз қандай тәсілмен көбірек қолдау көрсетпексіз?»;
* **Бағалау**: «Сіз оқушылардың материалды игеру деңгейін қалай тексеруді жоспарлайсыз?»;
* **Денсаулық және қауіпсіздік техникасын сақтау**;
* **Жалпы бағалау / рефлексия**: «Сабақтың қандай екі аспектісі жақсы өтті?…».

Бұлар ресми нысанда жоқ, ескі (2016–2021) үлгіден қалған қосымша бөлімдер.

## 3. Генератор үшін қорытынды

* **Міндетті тармақтар.** Генератор ресми нысанның 9 тармағын және 5 бағанды кестені **міндетті түрде** шығаруы керек.
* **Қосымша бөлімдер.** «Бағалау критерийлері», «Құндылықтарға баулу» және «Саралау / Бағалау / Денсаулық / Рефлексия» мұғалімдер іс жүзінде күтетін бөлімдер. Оларды қосымша (опция) ретінде беру ұсынылады.
* **Сабақтың кезеңдері.** Кезеңдерді «Сабақтың басы / ортасы / соңы» деп бөліп, әр кезеңге уақыт (мин) және әдіс атауын жазу керек.
* **Бағалау.** Бағалау бағанында әр тапсырмаға **дескриптор** беріледі, мүмкін болса балл да көрсетіледі.
* **Оқу мақсаттары.** Оқу мақсаты коды және мәтінімен бірге жазылады. Оларды ресми ұзақ мерзімді жоспардан алу керек: [`../uzaq-merzimdi-josparlar/`](../uzaq-merzimdi-josparlar/).

## 4. Ескі үлгі (жарамсыз)

zharar.com және bilimland.kz сайттарындағы ҚМЖ-лардың көбінде кесте мынадай:

| Сабақтың жоспарланған кезеңдері | Сабақтағы жоспарланған іс-әрекет | Ресурстар |
|---|---|---|

Бұл 3 бағанды ескі үлгі. Онда «Педагогтің әрекеті», «Оқушының әрекеті» және «Бағалау» бағандары жоқ, сондықтан ол ресми нысанға сай емес.
